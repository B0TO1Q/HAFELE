# Hafele Landscaping & Snow Removal — website

Draft website for Hafele Landscaping & Snow Removal LLC (Burlington, CT).

## What's here

- `index.html` — the page
- `styles.css` — styles
- `script.js` — the "Book a visit" flow and the services list
- `assets/` — job photos (straightened) and the walk-around video

No build step. Open `index.html` in a browser, or turn on GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root) to get a live link.

## How booking works right now

The customer picks a service, a day and a time window (snow skips the day),
then enters name, cell and address. **Send request** opens a text message to
(203) 560-6079 with everything filled in, ready to send. There's an email
fallback to hafelelandscapingllc@gmail.com if texting doesn't open.

Next step: connect the form to Jobber or a form service so requests land
automatically without the customer hitting send.
